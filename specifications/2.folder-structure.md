## 📂 Folder Structure (CI/CD infra and Angular App)
repo/
├─ .github/workflows/
│    └ deploy.yml         ← GitHub Actions Pipeline
├─ infra/terraform/       ← Terraform code
│    ├ backend.tf
│    ├ cloudrun.tf
│    ├ outputs.tf
│    ├ providers.tf
│    └ variables.tf
├─ src/
│ ├─ main.ts              ← Angular bootstrap entry point
│ ├─ index.html           ← Main HTML template
│ ├─ styles.scss          ← Global styles
│ └─ app/
│    ├─ app.component.ts  ← Root component
│    ├─ app.routes.ts     ← Routing configuration
│    ├─ pages/
│    │  ├─ home/home.component.ts  ← Search page (home)
│    │  └─ results/results.component.ts ← Results page
│    ├─ components/
│    │  ├─ search-form/search-form.component.ts
│    │  ├─ price-chart/price-chart.component.ts
│    │  ├─ summary-card/summary-card.component.ts
│    │  ├─ filter-sidebar/filter-sidebar.component.ts
│    │  └─ filter-modal/filter-modal.component.ts
│    ├─ services/
│    │  ├─ house.service.ts ← Fetch houses, calculate stats
│    │  └─ config.service.ts ← API configuration
│    └─ models/
│       └─ house.model.ts  ← House and Filter interfaces
├─ karma.conf.js          ← Karma test runner config
├─ angular.json           ← Angular CLI configuration
└─ Dockerfile             ← Angular for Cloud Run
